# skills — biblioteca de skills OpenCode

Migração incremental para Arquitetura Hexagonal (Strangler Fig).

| Skill | Quando usar |
|---|---|
| hexagonal-orquestradora | criar projeto novo ou migrar legado (coordena tudo) |
| hexagonal-diagnostico-legado | mapear legado e gerar `migration_plan.json` |
| hexagonal-scaffold-projeto-novo | scaffold greenfield hexagonal |
| hexagonal-testes-caracterizacao | congelar comportamento legado (Golden Master) |
| hexagonal-modelagem-visual-nucleo | especificar núcleo em 4 diagramas Mermaid |
| hexagonal-migrar-caso-de-uso | migrar 1 caso para o hexágono + Strangler Fig |
| hexagonal-guarda-arquitetura | portões de qualidade (`run_gates.sh`) |
| hexagonal-spec-builder | ideia em linguagem natural → `spec.md` + `domain_map.json` |
| hexagonal-relatorio-final | relatório executivo para leigos |
